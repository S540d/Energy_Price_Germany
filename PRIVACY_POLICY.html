3. Lokal gespeicherte Daten

Die App speichert folgende Daten ausschließlich auf Ihrem Gerät (Android: App-Speicher, Web: Browser-Speicher). Sie werden nicht an uns übertragen:

  • Einstellungen: Sprache, Darstellung (Hell/Dunkel), Land, Anzeige der Netzentgelte
  • Postleitzahl, falls Sie eine für regionale Daten eingeben
  • Preisalarm-Schwellen, falls gesetzt
  • Zwischengespeicherte Daten: Strompreise, Erneuerbaren-Anteil, Verlauf und regionale Werte

Sie können diese Daten jederzeit löschen, indem Sie die App deinstallieren, den App-Speicher in den Android-Einstellungen leeren oder im Browser die Website-Daten löschen.

4. Netzwerkverbindungen

Für ihre Funktion ruft die App Daten von folgenden Diensten ab. Dabei wird technisch bedingt Ihre IP-Adresse an den jeweiligen Server übermittelt. Ob und wie lange der Anbieter sie protokolliert, richtet sich nach dessen Datenschutzbestimmungen.

  • GitHub Pages (GitHub, Inc.), s540d.github.io: Auslieferung der Web-Version sowie der aufbereiteten Strompreis- und Erneuerbaren-Daten (bei jedem Datenabruf, auch in der Android-App). Die Daten stammen aus Energy Charts (Fraunhofer ISE) und aWATTar; diese Dienste werden von der App selbst nicht aufgerufen.
  • Energy Charts (Fraunhofer ISE), api.energy-charts.info: Abruf des regionalen Erneuerbaren-Anteils, wenn Sie eine Postleitzahl eingeben – dabei wird Ihre Postleitzahl übermittelt. Ohne eigene Postleitzahl fragt die App nur dann an, wenn bundesweite Werte für heute fehlen, und zwar mit einer festen Ersatz-Postleitzahl (Berlin, 10115) ohne Bezug zu Ihrem Standort. Die Android-App fragt direkt an.
  • Cloudflare (Cloudflare, Inc.), energypricegermany.sven4321.workers.dev: nur in der Web-Version, für dieselben Anfragen wie bei Energy Charts. Browser können die Energy-Charts-Schnittstelle nicht direkt abfragen; die Anfrage läuft deshalb über einen Weiterleitungsdienst bei Cloudflare, der dabei Postleitzahl und IP-Adresse erhält. Die Antwort wird dort bis zu einer Stunde je Postleitzahl zwischengespeichert, ohne Bezug zu Ihrer IP-Adresse.

Ohne eigene Postleitzahl werden keine Angaben zu Ihrem Standort übermittelt.

5. Berechtigungen (Android)

🔒 Privacy Policy

Last updated: October 25, 2026 (applies from app version 1.11.5)

No account. No tracking. No ads. No analytics.
The app itself does not collect personal data. As with any request over the internet, however, the servers contacted technically receive your IP address – see section 4.

1. Scope

This privacy policy applies to the Android app and the web version of "Energy Price Germany" (the "App"), developed by S540d.

2. Controller

Controller details: see Legal Notice (Impressum)
Contact: GitHub Issues

3. Data stored locally

The App stores the following data only on your device (Android: app storage, web: browser storage). It is not transmitted to us:

  • Settings: language, appearance (light/dark), country, grid fee display
  • Postal code, if you enter one for regional data
  • Price alert thresholds, if set
  • Cached data: electricity prices, renewable share, history and regional values

You can delete this data at any time by uninstalling the App, clearing the app storage in Android settings, or clearing the site data in your browser.

4. Network connections

To work, the App retrieves data from the following services. For technical reasons your IP address is transmitted to the respective server. Whether and for how long the provider logs it is governed by its own privacy policy.

  • GitHub Pages (GitHub, Inc.), s540d.github.io: delivers the web version and the prepared electricity price and renewable data (on every data request, including in the Android app). The data originates from Energy Charts (Fraunhofer ISE) and aWATTar; the App itself does not contact these services for it.
  • Energy Charts (Fraunhofer ISE), api.energy-charts.info: retrieves the regional renewable share if you enter a postal code – your postal code is transmitted. Without your own postal code, the App only queries it when nationwide values for today are missing, using a fixed substitute postal code (Berlin, 10115) unrelated to your location. The Android app contacts this service directly.
  • Cloudflare (Cloudflare, Inc.), energypricegermany.sven4321.workers.dev: web version only, for the same requests as Energy Charts. Browsers cannot query the Energy Charts interface directly, so the request is relayed through a forwarding service at Cloudflare, which receives the postal code and IP address. The response is cached there for up to one hour per postal code, without reference to your IP address.

Without your own postal code, no information about your location is transmitted.

5. Permissions (Android)

INTERNET – retrieve the data listed in section 4
ACCESS_NETWORK_STATE – check whether a network connection is available

In the web version, the App asks for permission to show browser notifications only if you use a price alert. Notifications are created locally in the browser while the page is open; no push service is used.

  • No ads and no advertising trackers
  • No crash reporting tools
  • No cookies
  • No user account

7. External links

Links in the App (e.g. GitHub, Google Play, Ko-fi) open in your browser. The privacy policies of the respective providers apply to those sites.

8. Your rights

Since we do not store personal data, we hold no data about you. You can delete your locally stored data yourself at any time (section 3). For questions, please use the contact details in section 2.
